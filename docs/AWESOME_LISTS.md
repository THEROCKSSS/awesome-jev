## Why this list exists

Twenty-plus parallel awesome lists means the same projects are curated twenty times and
missed twenty times differently. This catalog is the merged, deduplicated superset —
verified against live GitHub metadata (every entry confirmed to exist, with real star
counts and languages) rather than hand-typed markdown.
