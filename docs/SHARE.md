Copy this message into Discord or anywhere your community finds projects:

> Been looking for what people are actually building with Jev / TypeSafe System One? I put together **Awesome Jev**: a visual, searchable map of the ecosystem with dedicated pages that load each project's own README. Browse by category or language, open the original GitHub repo, and come back later—the catalog is refreshed daily. If you built something that belongs here, send a repo or PR. Explore it: https://therocksss.github.io/awesome-jev/ ✦ Source: https://github.com/THEROCKSSS/awesome-jev

The catalog is community maintained and is not affiliated with TypeSafe. Repository descriptions and stars are snapshots; README content comes from GitHub when a detail page opens.
